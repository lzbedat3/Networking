 IP
 • The IP address is the address of the host on the
 internet or local network.
 • An IP address is a string of numbers separated by
 periods. IP addresses are expressed as a set of four
 numbers (octets) — an example address might be
 192.158.1.38. Each number in the set can range
 from 0 to 255. So, the full IP addressing range goes
 from 0.0.0.0 to 255.255.255.255. Address is
 converted to binary in order to be able to route
 and forward the packets.
255.255.255.255 = 11111111.11111111.11111111.11111111
Private IP VS Public IP
• Private IP address scope is local to present
 network. And is used to communicate within the
 network.
• Public IP address scope is global. And is used to
 communicate outside the network.

Subnet & subnet mask
• Subnet - A portion of a network that
 shares a particular subnet address.
• Subnet mask - A 32-bit combination
 used to describe which portion of an
 address refers to the subnet and which
 part refers to the host.
• Every IP address is composed of a
 network component and a host
 component
 • Subnet part are the high order bits
 • Host part are the low order bits
• Once you have the address and the
 mask represented in binary, then
 identification of the network and host ID
 is easier. Any address bits which have
 corresponding mask bits set to 1
 represent the network ID. Any address
 bits that have corresponding mask bits
 set to 0 represent the node ID.
• Purpose: to identify which part of an IP
 address is the network component and
 which part is the host component
