RTT and HTTP 1.0
 RTT (Round Trip Time)
 time for a small packet to go
 client → server → client
Per object:
• 1 RTT – open TCP connection
• 1 RTT – request + first bytes
• + file transmission time
 time per object = 2·RTT + transmission time

 Exercise
Exercise: page load time
A page has 1 base HTML file and 10 small images.
 Given
 RTT = 10 ms
 Transmission time is negligible (ignore it)
How long until the whole page is loaded with:
1. HTTP 1.0 – non-persistent, one object at a time?
2. HTTP 1.1 – persistent, one request at a time?
Exercise: solution
 HTTP 1.0 HTTP 1.1
 11 objects × 2 RTT 2 RTT (connect + HTML)
 = 22 RTT + 10 × 1 RTT = 12 RTT
 = 220 ms = 120 ms
 Bonus: pipelining (HTTP 1.1)
 send all 10 requests back-to-back → 2 RTT + 1 RTT = 30 ms

HTTP methods
Method What it does
GET request an object (usually no body)
POST send data to the server in the body (forms)
HEAD like GET, but return headers only
PUT upload / replace a file at the URL
DELETE delete the object at the URL
CONNECT open a tunnel (used by proxies)
The method is always one word, in capital letters
